# SQL-Food-Delivery-Management-System

# 🍔 Swiggy SQL Data Analysis Project

## 📌 Project Overview

This project is a **MySQL-based food delivery database project** inspired by Swiggy. It is designed to store, manage, and analyze data related to customers, restaurants, menu items, orders, deliveries, payments, and reviews.

The project demonstrates practical SQL skills by using a relational database to answer real-world business questions and generate useful insights.

## 🎯 Objectives

* Design and manage a relational database.
* Store customer, restaurant, order, and payment information.
* Analyze food delivery business data using SQL.
* Practice SQL queries on real-world scenarios.
* Generate useful insights from multiple related tables.

## 🛠️ Technologies Used

* **SQL**

## 📊 Data Analysis Performed

### 👥 Customer Analysis

* Display the first 10 customers.
* Display customers alphabetically.
* Find unique customer cities.
* Count registered customers.
* Display the latest registered customers.

### 🍽️ Restaurant & Menu Analysis

* Find restaurants located in Bengaluru.
* Display the first five restaurants.
* Display vegetarian menu items.
* Display menu item names, categories, and prices.
* Calculate menu prices after a 5% service charge.

### 📦 Order Analysis

* Count the total number of orders.
* Display customer name, order ID, order date, and total amount.
* Display order ID, restaurant name, order date, and order amount.

### 💳 Payment Analysis

* Display payment details.
* Find the highest payment amounts.
* Display completed payments.
* Calculate total revenue from completed payments.
* Analyze different payment statuses.

### 🚴 Delivery Analysis

* Display delivery information.
* Find deliveries that received ratings.
* Analyze delivery-related records.

### ⭐ Review Analysis

* Display customer reviews.
* Find reviews with ratings below 3.
* Analyze customer ratings.
